# Практическая работа JS-01 — JavaScript: функции, массивы и объекты

## Анализатор каталога товаров

Небольшое приложение для анализа каталога: считает стоимость товаров и всего склада, находит самый дорогой товар, фильтрует и ищет позиции, показывает статистику по категориям и позволяет менять остатки без изменения исходного массива.

## Запуск

1. Откройте папку проекта в редакторе.
2. Запустите локальный сервер из этой папки, например:

   ```bash
   python -m http.server 8000
   ```

3. Откройте в браузере http://localhost:8000.

> Используется JavaScript ES Modules, поэтому страницу нужно открывать через локальный сервер, а не напрямую через file://.

## Структура

- `index.html` — разметка приложения.
- `style.css` — оформление интерфейса и адаптивная сетка.
- `js/products.js` — исходный каталог и функции обработки данных.
- `js/main.js` — связь функций с интерфейсом, фильтрация, сортировка, изменение количества и отчёт в консоли.

## Реализованные функции

- `getProductTotal(product)` — стоимость всех единиц конкретного товара.
- `getTotalInventoryValue(products)` — общая стоимость каталога.
- `getMostExpensiveProduct(products)` — товар с максимальной ценой за единицу.
- `filterByCategory(products, category)` — новый массив товаров выбранной категории.
- `findProduct(products, id)` — поиск товара по ID.
- `getAvailableProducts(products)` — товары с положительным остатком.
- `getCategoryStatistics(products)` — статистика количества позиций, единиц и стоимости по категориям.
- `updateProductQuantity(products, id, quantity)` — новый массив с обновлённым остатком, исходные данные не мутируются.
- `sortProductsByPrice(products, direction)` — отсортированная копия каталога.

При загрузке страницы в консоль браузера выводится отчёт с результатами обязательных функций.

## Проверка

Можно менять категорию, искать товар по названию, переключать сортировку по цене и обновлять количество товара. Все изменения отображаются в интерфейсе; исходный массив каталога остаётся неизменным.
