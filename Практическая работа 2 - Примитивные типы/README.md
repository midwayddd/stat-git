# Практическая работа 2 — Примитивные типы

## Задание
«Учёт цен и доступности товаров».

## Что реализовано
- Типизированные массивы `string[]`, `number[]`, `boolean[]` и массив кортежей.
- Не менее пяти товарных записей.
- Выборка доступных позиций через `filter()`, преобразование через `map()`, сумма через `reduce()`.
- Литеральный тип статуса, примеры `null` и `undefined`.
- Проверка строки, преобразуемой в число, через `Number()` и `Number.isFinite()`.
- Функции с возвращаемыми типами `void` и `never`.

## Запуск
```bash
npm install
npm run build
```

Скомпилированный файл появится в `dist/catalog.js`. Для проверки без генерации файлов используйте `npm run check`.
