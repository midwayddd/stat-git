# Практическая работа 3 — Типы объектов, type и interface

## Задание
«Каталог товаров с поставщиками».

## Что реализовано
- Модели поставщика и контактов с вложенными необязательными полями.
- Интерфейс товара с `readonly id`, необязательным описанием и вложенным поставщиком.
- Массив из шести товаров с разными категориями, ценами, наличием и поставщиками.
- Выборка `filter()`, преобразование `map()`, поиск `find()` с проверкой результата.
- Безопасная обработка необязательных полей и изменение обычных свойств.
- Дополнительные задания: `ProductId`, `DigitalProduct extends Product`, структурная типизация и повторное использование Supplier.

## Запуск
```bash
npm install
npm run build
```

Скомпилированный файл появится в `dist/catalog.js`. Для проверки без генерации файлов используйте `npm run check`.
