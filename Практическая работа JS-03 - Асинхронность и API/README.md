# JS-03 — Асинхронность и работа с API

## Проект
Интерактивный каталог стран. Приложение получает список стран из открытого REST Countries API, показывает состояние загрузки, обрабатывает ошибки сети и HTTP, позволяет искать, фильтровать и сортировать результаты.

## Запуск
1. Откройте папку проекта в VS Code.
2. Запустите локальный сервер (например, расширением Live Server).
3. Откройте `index.html` через локальный сервер. Не запускайте через `file://`: браузерные ES-модули и сетевые запросы требуют корректного origin.
4. Для загрузки данных требуется подключение к Интернету.

API: https://restcountries.com/v3.1/all?fields=name,flags,capital,region,population,cca3

## Файлы
- `index.html` — разметка страницы, форма поиска и фильтры.
- `style.css` — оформление каталога и адаптивная сетка.
- `js/main.js` — запрос к API, проверка ответа, состояния загрузки/ошибки и действия пользователя.

## Что реализовано
- `async/await`, `fetch()`, проверка `response.ok` и структуры JSON.
- Отдельные состояния загрузки, ошибки и пустого результата.
- Поиск по названию и столице, фильтр по региону, сортировка.
- Безопасное создание карточек через DOM и `textContent`, без вставки данных API через `innerHTML`.
- Повторная загрузка после ошибки.
