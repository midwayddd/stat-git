# Практическая работа 4 — Типизация функций и callback

## Задание
«Обработка заказов и расчёт стоимости».

## Что реализовано
- Интерфейсы `OrderItem` и `Order`, а также тип функции `PriceFormatter`.
- Три тестовых заказа с несколькими позициями в каждом.
- Расчёт стоимости позиции и суммы заказа через `reduce()`.
- Применение скидки с проверкой диапазона от 0 до 100%.
- Форматирование цены с валютой и передача форматтера через callback.
- Выбор позиций через `filter()` с двумя разными callback.
- Преобразование данных через `map()` и поиск через `find()` с проверкой `undefined`.
- Дополнительные задания: `OrderPredicate`, rest-параметр, callback-преобразователь, перегрузка функции и объект параметров.

## Файл с программой
- `src/orders.ts` — модели данных, функции расчёта и форматирования, обработка заказов и демонстрационные вызовы.

## Как запустить
В терминале из этой папки выполните:

```bash
npm install
npm run build
```

После компиляции JavaScript-файл появится в `dist/orders.js`. Для проверки типов без создания файлов используйте `npm run check`.

## Краткое объяснение
В программе каждый заказ состоит из покупателя и массива товарных позиций. Сначала рассчитывается стоимость каждой позиции с учётом количества, затем складываются все позиции и применяется скидка. Функция форматирования получает другую функцию через callback, поэтому способ отображения цены можно менять без изменения расчётов.

Метод `filter()` отбирает позиции по переданному условию, `map()` создаёт массив названий, `find()` ищет позицию по ID, а `reduce()` считает суммы. Дополнительные функции показывают типизацию callback для заказов, произвольное число аргументов и перегрузку.
