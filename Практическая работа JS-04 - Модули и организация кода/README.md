# JS-04 — Модули и организация кода

## Проект
«Фокус» — планировщик учебных задач. Можно добавлять задачи, отмечать выполнение, фильтровать список и удалять записи. Данные сохраняются между перезапусками.

## Запуск
Откройте папку в VS Code и запустите `index.html` через Live Server или другой локальный HTTP-сервер. ES-модули не следует запускать напрямую через `file://`.

## Структура и назначение скриптов
- `js/main.js` — точка входа: связывает DOM, хранилище и операции, назначает обработчики один раз.
- `js/tasks.js` — чистые операции над задачами: создание, переключение статуса, фильтрация.
- `js/storage.js` — чтение и запись localStorage, обработка повреждённого JSON и неизвестного формата.
- `js/ui.js` — отображение задач и счётчиков через DOM.

## Требования
Использованы ES-модули, именованные import/export, разделение ответственности, несколько действий пользователя, проверка ввода и восстановление данных из localStorage.
