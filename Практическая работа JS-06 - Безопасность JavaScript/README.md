# JS-06 — Безопасность JavaScript

## Проект
«Личные заметки» — небольшое приложение для создания и хранения заметок в браузере. Работа демонстрирует валидацию входных данных, безопасный вывод текста, проверку локального хранилища и обработку ошибок.

## Запуск
Откройте папку в VS Code и запустите `index.html` через Live Server или другой локальный HTTP-сервер.

## Назначение скриптов
- `js/validation.js` — нормализация и предметные проверки заголовка и текста заметки.
- `js/storage.js` — безопасная загрузка/сохранение localStorage, обработка отсутствующих и повреждённых данных.
- `js/ui.js` — создание DOM-элементов; пользовательские значения вставляются через `textContent`.
- `js/main.js` — обработчики формы, поиск, удаление и связь модулей.

## Меры безопасности
- Заголовок: 3–60 символов; текст: 5–500 символов; пустые и дублирующиеся заголовки отклоняются.
- Недоверенный текст отображается через `textContent`, не через `innerHTML`.
- Нет `eval()`, `Function()` и строковых обработчиков событий.
- JSON из localStorage проверяется после разбора; ошибки чтения/записи обрабатываются.
- CSP ограничивает источники скриптов, объектов и отправку форм.
- Для проверки попробуйте пустые поля, одни пробелы, слишком длинный текст и строку `<img src=x onerror=alert(1)>`: она должна отобразиться как обычный текст.
