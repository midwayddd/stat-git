# JS-05 — Прототипы, классы и ООП

## Проект
«Игровая полка» — коллекция видеоигр. Можно добавлять игры, менять статус прохождения, удалять записи и фильтровать библиотеку. Модель построена на двух классах с разными обязанностями.

## Запуск
Откройте папку в VS Code и запустите `index.html` через Live Server или другой локальный HTTP-сервер.

## Назначение скриптов
- `js/models.js` — классы `Game` и `GameLibrary`: состояние, проверка правил, методы сущностей и коллекции.
- `js/storage.js` — сохранение и восстановление коллекции; при загрузке JSON создаются новые экземпляры `Game`.
- `js/ui.js` — построение карточек и обновление счётчиков через DOM.
- `js/main.js` — точка входа, обработчики формы, фильтров и действий пользователя.

## Объектная модель
- `Game` отвечает за одну игру: название, платформа, жанр и статус; метод `setStatus()` проверяет допустимое состояние.
- `GameLibrary` отвечает за коллекцию: добавление, удаление, поиск и фильтрация экземпляров.
- Экземпляры создаются оператором `new` и используются интерфейсом, а не только демонстрируют синтаксис классов.
