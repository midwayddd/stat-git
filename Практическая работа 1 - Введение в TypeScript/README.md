# Практическая работа 1 — Введение в TypeScript

## Задание
Учебный браузерный проект «Карточка заказа»: вычисление стоимости по цене и количеству, вывод на страницу и в консоль, безопасная проверка DOM-элементов и настройка TypeScript.

## Что реализовано
- Явные типы `string` и `number`, автоматический вывод типа результата.
- Расчёт суммы и цены со скидкой через выражения.
- Проверки цены, количества и процента скидки.
- Проверка наличия HTML-элементов перед обращением к ним.
- `.gitignore` исключает `node_modules/` и `dist/`.

## Запуск
Из этой папки выполните:

```bash
npm install
npm run build
```

Затем откройте `index.html` через локальный сервер (например, Live Server). Результат будет показан на странице и в консоли браузера.

Дополнительно: `npm run check` проверяет типы без генерации файлов.
